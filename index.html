Armazenamento e responsabilidade pelos dados

As receitas cadastradas são armazenadas localmente no navegador deste dispositivo, por meio do armazenamento local. Elas não são enviadas para um servidor ou conta online.

Os dados podem ser perdidos se o histórico ou os dados do navegador forem apagados, se o navegador for reinstalado, se o dispositivo apresentar defeito, se o arquivo for aberto em outro navegador ou se houver troca de computador ou celular.

Não nos responsabilizamos por perdas, exclusões, corrupção ou indisponibilidade das receitas armazenadas. Para reduzir o risco de perda, use regularmente a opção Exportar backup e guarde o arquivo JSON em um local seguro.
